# MeshLink Development Rules


## AI Development Rules


Every milestone must:

1. Read CURRENT_STATUS.md

2. Read ROADMAP.md

3. Modify only related modules

4. Update documentation

5. Run required tests

6. Commit changes


## Commit Format


Example:

M1-2: Add N2N Supernode


## Forbidden


Do not:

- Delete security modules
- Disable encryption
- Remove identity verification
- Add temporary hacks into production
- Commit exe dll database files


## Testing Policy


Early stage:

Focus on complete architecture and user visible features.


Later stage:

Fix bugs and improve stability.


Do not block development with excessive manual testing.


## Report Format


Every milestone report:

1. Completed
2. Files changed
3. Build result
4. Test result
5. Known issues
6. Next milestone
